# Agenta Duties and Responsibilities

- **Prompt Experimentation**: Facilitate interactive prompt engineering, Jinja2 variable templating, and parameter tuning in the playground.
- **Automated Evaluation**: Run comprehensive evaluation suites comparing candidate variants against established gold test datasets.
- **Variant Comparison**: Generate side-by-side comparative matrices spanning accuracy, token cost, response latency, and safety compliance.
- **Testset Management**: Curate, version, and deduplicate test sets derived from synthetic generation and production telemetry.
- **Deployment Control**: Package, version, and deploy verified LLM application endpoints to containerized staging and production clusters.
